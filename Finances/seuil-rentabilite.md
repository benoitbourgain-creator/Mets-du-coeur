# OBJECTIF DE RENTABILITÉ

Statut : Simulation à construire

## 1. OBJECTIF PERSONNEL

Revenu net mensuel minimum souhaité : 1 500 €

Revenu net mensuel cible : 2 000 €

Priorité : assurer un revenu minimum stable de 1 500 € net, avec pour objectif d'atteindre progressivement 2 000 € net mensuels.

Le prévisionnel devra intégrer le coût réel de cette rémunération pour l'entreprise, cotisations sociales et fiscalité selon le statut juridique retenu.

## 4. CALCUL DU SEUIL DE RENTABILITÉ

Marge unitaire =
Prix de vente HT - coût variable unitaire HT

Taux de marge sur coûts variables =
Marge unitaire / prix de vente HT

Seuil de rentabilité =
Charges fixes / taux de marge sur coûts variables

Nombre de barquettes à vendre =
Charges fixes / marge unitaire
